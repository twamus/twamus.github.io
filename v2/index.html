qDIR64

VB.NET Python 2014

The original qDIR was an in-house file/data management tool written in qBASIC, used to process and manage mailing data lists. These utilities were rewritten in Visual Basic and Python around 2014.

As 16-bit applications reached end of life, our old data tools were about to be left in the dust. We needed a solution that survived the deprecation, retained compatibility with older files, and allowed future growth without breaking the core system or the workflow.

Notable features

  • Fully keyboard-navigable to speed up processing: spacebar to select, tab to switch tools, back arrow to swap between files and folders.
  • Customizable toolbar; enable and disable tools with drag and drop.
  • Purely modular: core written in VB, supporting tools written in Python and other languages.

Python tool descriptions

  • ADD: blindly combines multiple CSV files; useful for combining standardized lists.
  • DBF to CSV: converts DBIII files to CSV format.
  • ODOA Test: strips line breaks out of the middle of CSV fields.
  • Satori Prep: prepares CSVs for Satori Bulk Mailer, preserving fields the tool shouldn't touch.
  • Shuffle: prepares items for N-up printing so stacked postcards come out in the right order.
  • Split: splits one CSV into multiple by a field value.
  • Title Case / Uppercase: field case normalizers.

VB tool descriptions

  • DBQ: quick CSV viewer/editor (for when Excel dropped leading zeros on zip codes).
  • LLoDD: generated layout previews and .ADM files for inkjet address printers.
  • Merge: merges CSVs of varying contents into one clean master; user picks which fields merge.
  • Zip4 Finder: pulled from the USPS website to verify Zip+4 when Satori missed the mark.

Project Management Tool

PHP JavaScript SQL MAPP stack

Due to the nature of proprietary information, I can't share the name or screenshots of this one, so I referred to it as PMT, and recreated the interface from memory in Microsoft Paint.

Workflow originally ran on Excel documents updated throughout the day, a logistical nightmare when everyone needed the same current version. This tool centrally hosted work orders for clients shipping to stores nationwide, with templates and presets to streamline repeat work. It was a fully functional project management tool with complete integration into packing, shipping, and tracking.

Built on a MAPP stack (Mac Server, Apache, PostgreSQL, PHP).

Project management (core) features

  • Export items to Excel spreadsheet.
  • Billing amortization of company fees based on percentage of billable items per store and project.
  • Presets of common items and the ability to copy items between stores or tabs.
  • Multiple budgeting sheets.

Packing and shipping integration

  • Packing list generation with QR codes as unique package identifiers.
  • Override in the packing system when shipments needed a different destination.
  • End-of-day tracking reports for project managers.
  • Automatic package delivery status and location updates from freight and domestic carriers.

Shipping Tool

C# FedEx Web Services

Designed to complete the loop between the packing system and the project management tool, intended as the primary shipping method. The field sizing looks a little off because of a mix of window previews, a newer Visual Studio, and a newer .NET version.

It never officially launched into production, which means I can share more details than the PMT. All options are fully functional unless noted as in development.

Shipping-related features

  • Label and packing list reprinting.
  • Mettler-Toledo scale integration.
  • Third-party billing, Saturday delivery, and direct-signature-required options.
  • Filtering large job item lists by item type or ID.

Company-specific features
